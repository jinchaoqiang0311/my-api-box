# サービス利用ガイド

ここでは、厳選したサービスについて、アカウント追加、API Key の保存、モデル価格の確認、設定のエクスポートまでを説明します。

これは対応サイトの完全な一覧ではありません。特に便利なサービス、設定方法に特徴があるサービス、またはプロジェクトと協力関係にあるサービスに、個別のガイドを用意しています。すべての対応状況は[対応サイト一覧](./supported-sites.md)を確認してください。

My API Box をまだインストールしていない場合は、先に[はじめに](./get-started.md)を確認してください。

## サービスを選ぶ

| サービス | 用途 | ガイド |
| --- | --- | --- |
| OpenRouter | OpenRouter アカウントを追加し、API Key の管理とモデル価格の確認を行います。 | [ガイドを見る](./service-guides/openrouter.md) |
